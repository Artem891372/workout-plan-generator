# Workout Plan Generator

Генератор персонализированных программ тренировок на Streamlit. Подбирает упражнения, распределяет подходы по дням и строит план прогрессии нагрузок на несколько недель на основе научных рекомендаций по объёму тренировок (гипертрофия).

## Возможности

- **База из 70+ упражнений** с коэффициентами вовлечённости мышечных групп
- **Выбор мышечных групп** для тренировки и целевых объёмов (подходов в неделю)
- **Три типа сплитов**: Full Body, Верх/Низ, Push/Pull/Legs
- **Компактный автоподбор упражнений**: базовое движение на крупную мышцу, затем изоляция на конкретную активацию — без раздувания списка «всем, что есть в пуле»
- **Плавное распределение объёма**: подходы меняются постепенно, без многонедельных плато и резких скачков; при упоре в лимит прогрессирует нагрузка (%1ПМ)
- **Распределение подходов** по дням недели с учётом лимитов на день и на упражнение
- **Типизация подходов**: лёгкие / средние / тяжёлые с RPE-рекомендациями
- **Планы прогрессии**: линейная и волновая (wave) периодизация на 9 недель
- **Анализ недобора объёма**: показывает, какие мышечные группы не добирают целевой объём и почему; не предлагает «добавить упражнения», если объём можно добрать на уже выбранных
- **Рекомендации по повторениям** на основе time-under-tension (TUT) для цели (сила / гипертрофия / выносливость)
- **Ориентир нагрузки** в %1ПМ по неделям (в волне предусмотрены разгрузки)
- **Выгрузка программы** в Excel и CSV: русские заголовки, диапазоны через тире, без лишних скобок, оформление с разделением дней и сводкой по неделям

## Запуск

```bash
pip install streamlit pandas openpyxl
streamlit run app.py
```

Откройте браузер по адресу, который покажет Streamlit (обычно http://localhost:8501).

## Использование

1. **Конфигурация** — выберите мышечные группы, сплит, количество тренировочных дней, тип прогрессии и кардио.
2. **Упражнения** — при желании вручную замените автоматически подобранные упражнения.
3. **Программа** — сгенерируйте план и посмотрите распределение по дням.
4. **Просмотр** — детальные таблицы по каждой неделе.
5. **Выгрузка** — скачайте программу.

## Структура

- `app.py` — всё приложение (данные упражнений, алгоритм распределения объёма, UI на Streamlit)

## Примечания

- Целевые объёмы по умолчанию основаны на рекомендациях 10–20 сетов в неделю на мышечную группу для гипертрофии.
- Объём считается по **рабочим подходам** (подходы × коэффициент вовлечённости мышцы), а не по «стимулу» лёгких/тяжёлых подходов. Поэтому 10 подходов на грудь — это действительно 10 рабочих подходов, а не 20 «лёгких».
- Действуют разумные лимиты: до 25 подходов в день, до 12 подходов в неделю на базовое упражнение и до 9 на изоляцию. Если цель упирается в лимит, приложение честно показывает это и предлагает прогрессировать нагрузку, а не добавлять упражнения.
- Автоподбор по умолчанию выбирает крупные группы + руки + пресс; остальные мышцы можно добавить вручную.
- Все параметры (упражнения, объёмы, TUT) можно расширять прямо в коде в словарях `EXERCISES` и `DEFAULT_TARGET_VOLUME_MG`.
