# Workout Plan Generator

Генератор персонализированных программ тренировок на Streamlit. Подбирает упражнения, распределяет подходы по дням и строит план прогрессии нагрузок на несколько недель на основе научных рекомендаций по объёму тренировок (гипертрофия).

## Возможности

- **База из 70+ упражнений** с коэффициентами вовлечённости мышечных групп
- **Выбор мышечных групп** для тренировки и целевых объёмов (подходов в неделю)
- **Три типа сплитов**: Full Body, Верх/Низ, Push/Pull/Legs
- **Распределение подходов** по дням недели с учётом лимита на день
- **Типизация подходов**: лёгкие / средние / тяжёлые с RPE-рекомендациями
- **Планы прогрессии**: линейная и волновая (wave) периодизация на 9 недель
- **Анализ недобора объёма**: показывает, какие мышечные группы не добирают целевой объём и почему
- **Рекомендации по повторениям** на основе time-under-tension (TUT) для цели (сила / гипертрофия / выносливость)
- **Выгрузка программы** в файл

## Запуск

```bash
pip install streamlit pandas
streamlit run app.py
```

Откройте браузер по адресу, который покажет Streamlit (обычно http://localhost:8501).

## Использование

1. **Конфигурация** — выберите мышечные группы, сплит, количество тренировочных дней, тип прогрессии и кардио.
2. **Упражнения** — при желании вручную замените автоматически подобранные упражнения.
3. **Программа** — сгенерируйте план и посмотрите распределение по дням.
4. **Просмотр** — детальные таблицы по каждой неделе.
5. **Выгрузка** — скачайте программу.

## Структура

- `app.py` — всё приложение (данные упражнений, алгоритм распределения объёма, UI на Streamlit)

## Примечания

- Целевые объёмы по умолчанию основаны на рекомендациях 10–20 сетов в неделю на мышечную группу для гипертрофии.
- Все параметры (упражнения, объёмы, TUT) можно расширять прямо в коде в словарях `EXERCISES` и `DEFAULT_TARGET_VOLUME_MG`.
